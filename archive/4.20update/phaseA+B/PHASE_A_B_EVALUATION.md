## 一、Phase A 实现评估

### A1. 质量评分系统 ⚠️ **严重问题**

**当前实现** (`pose_estimator.py` L8-67):
```python
def compute_quality_score(pose_dict, ellipse_metrics=None):
    # 完全基于轴比的简化版本
    axis_ratio = pose_dict.get('axis_ratio', 0.5)
    
    if axis_ratio <= 0.0 or axis_ratio > 1.0:
        quality_score = 0.0
    elif axis_ratio < 0.05:
        quality_score = 0.4
    elif axis_ratio < 0.15:
        quality_score = 0.55
    # ... 更多区间
    
    # ellipse_metrics 作用很弱，只是微调
    if ellipse_metrics and 'coverage' in ellipse_metrics:
        if coverage < 0.4:
            quality_score *= 0.7  # 只降权30%
```

**根本问题**:

1. **轴比权重过大，其他指标形同虚设**
   - 轴比本质上反映的是**观看角度**，不是**位姿精度**
   - 例：垂直看下来（轴比接近1）的位姿，质量反而最高
   - 但实际上，边缘欠清晰、遮挡、光线不足都会导致边缘检测失败

2. **椭圆指标没有真正约束**
   ```python
   # coverage = 0.3, residual = 2.5 时
   quality_score = 0.85 * 0.7 * 0.85 = 0.507
   # 仍然 > QUALITY_MIN_PUBLISH (0.2)，被发布！
   ```

3. **覆盖率计算本身有缺陷**
   ```python
   coverage = min(1.0, len(pts_2d) / (perimeter_approx / 2.0))
   # 问题：边缘点数是检测结果，not 真实覆盖率
   # 在高分辨率或边缘清晰时，点数多但不代表精度高
   ```

4. **残差计算不反映位姿误差**
   ```python
   residual = np.mean(np.abs(norm_dist - 1.0))
   # 这是椭圆边界的点到期望距离
   # 但点的噪声（±2-3px）直接转换为位姿噪声（±20-50mm）
   # 当 residual=1.5px 时，位置误差可能已经 ±30mm
   ```

5. **质量门控阈值极其宽松**
   ```python
   QUALITY_MIN_PUBLISH = 0.2  # 只要质量分 > 0.2 就发布！
   # 这几乎没有过滤任何东西
   ```

**定量分析**:
- 对于5cm圆柱，在 f_x ≈ 900px 的焦距下
- 长轴 MA ≈ 180px（近距0.3m）到 60px（远距1m）
- 轴比从 0.05（近距侧视） 到 0.95（远距近垂直）
- **当前质量分** 几乎全量 > 0.5，形同虚设

   ```python
   # - 从接收到发布的延迟 700ms
   # - 在运动场景中，预测能力完全失效

   ```

4. **短时稳态假设不成立**
   - 机械臂或工件可能持续运动
   - "稳态"的概念只对静止目标有效
   - 融合反而引入延迟

**定量影响**:
- 抖动改善可能 20-30%（融合确实有平滑作用）
- 但延迟增加 700ms，对运动控制造成 ±350mm 预测误差

**评估**:

✅ **改进**:
- 加权最小二乘避免了离群点的强影响
- 扩展到0.70~1.30的容差提升了容错性
- 返回 fit_score 为后续质量评分提供参考

❌ **根本局限**:

1. **轴比方法的数学上限**
   
   椭圆轴比 $r = \frac{b}{a}$ 反演倾角 $\theta$：
   $$r = \cos(\theta)$$
   
   导数：$\frac{dr}{d\theta} = -\sin(\theta)$
   
   在 $\theta$ 接近 0° 或 90° 时：
   - $\frac{dr}{d\theta} \approx 0$ （90°处）：轴比变化极慢，微小误差导致大角度误差
   - 例：轴比误差 ±0.02 → 倾角误差 ±3~5°
   
   **实际拟合精度**:
   ```
   椭圆边界点误差：±2-3px (检测、量化)
   转换为轴比误差：±0.01-0.03
   转换为倾角误差：±0.5~5° (取决于视角)
   ```

2. **当前拟合策略的限制**
   ```python
   # 仅使用 inliers (0.70 ~ 1.30 范围)
   # 当边缘不完整（例：口沿部分遮挡）时
   # inliers 数量 < 20，拟合无法继续
   
   # 只保留权重足够高的点
   # 但权重 = 1 / (|norm_dist - 1| + 0.1)
   # 这与椭圆几何关系不大，只是统计上接近边界
   ```

3. **3D位置计算的级联误差**
   ```
   长轴 MA (±3px误差) → Z 深度 (±10-15mm误差)
   
   Z = f_x * D_real / MA
   
   对于 5cm 圆柱：
   - 焦距 f_x = 900px
   - 真实直径 = 0.05m = 50mm
   - 长轴 MA = 900 * 50 / Z (mm)
   
   示例：Z = 0.3m (近距)
   - MA ≈ 150px
   - 若 MA 误差 ±3px → Z 误差 ±6mm ✓ 可接受
   
   但若 MA 误差 ±5px (遮挡、边缘模糊)
   - Z 误差 ±10mm ✗ 已接近 ±5mm 精度的极限
   
   加上法向误差导致的 X/Y 偏移
   - 总误差可能达 ±15-20mm ✗ 超出要求
   ```

4. **轴比约束的效果有限**
   ```python
   if prior_axis_ratio is not None:
       constrained_ratio = refined_ratio * 0.2 + prior_axis_ratio * 0.8
   
   # 权重 80% 很高，但
   # 若先验轴比本身就有偏差（例：前一帧光线不足）
   # 会将错误传播下去
   ```

**定量诊断**: 
即使 Phase B 完美实现，轴比方法的**倾角精度上限**约 ±1°，**转换为3D位置误差** ±8-12mm，对5cm目标**仍不满足 ±5mm 要求**。

## 三、根本问题诊断

### 问题 1: 质量评分形同虚设 🔴

**表现**:
- "质量分数聊胜于无" → 描述准确
- QUALITY_MIN_PUBLISH = 0.2 形同虚设
- 坏观测（遮挡、模糊、离群）也被发布

**根因**:
- 轴比不能代表位姿精度
- 椭圆指标的权重太小或计算方式不合理
- 没有直接衡量 3D 位置误差的指标

**修复难度**: 中等（需要重新设计评分逻辑）

---

### 问题 2: 精度无法达到 ±5mm ⚠️

**证据**:
- 轴比方法倾角精度上限 ±1°
- 转换为3D位置误差 ±8-12mm
- 5cm 目标要求 ±5mm，**已经被轴比方法超出一倍**

**数学上的死墙**:
```
椭圆轮廓精度：±2-3px（检测限制）
    ↓
轴比精度：±0.01-0.03（级联误差）
    ↓
倾角精度：±0.5~5°（导数敏感性）
    ↓
3D位置误差：±8-20mm（级联到 X/Y/Z）
```

**修复难度**: 很高（需要非线性重投影优化）→ **Phase D 必需**

---

### 问题 3: 融合延迟破坏控制实时性 ⚠️

**当前**:
- 700ms 融合延迟
- 对运动目标预测误差 ±350mm

**修复难度**: 低（改参数或改策略）→ **可立即调整**

## 五、推荐方案

### 方案 A: 短期改进（1-2天） - 修补 Phase A/B

**可行性**: **有限**，因为轴比方法本质上已接近精度上限

   - 融合：边缘清晰度、覆盖率、残差、几何一致性
   - 设置合理的阈值，保证 ≥60% 坏观测被拒

2. **调整融合参数** ⚠️
   - 减少 BURST_SAMPLE_COUNT 从 7 → 3（延迟 300ms → 150ms）
   - 只融合质量 > 0.65 的样本
   - 增加发布频率（不等待融合完成）

3. **启用自适应 dilation** ✅
   - 改为 `max(5, min(25, body_w * 0.15))`
   - 改善近距edge检测

4. **预期改善**:
   - 位置抖动：8-10mm → 6-8mm （改善 ~25%）
   - 拒发率：20% → 50-60% （改善 ✓）
   - 延迟：700ms → 150ms （改善 ✓）
   - **但 ±5mm 精度仍无法达到** ❌

---

### 方案 B: 跳跃到 Phase D（2-3天） - 非线性重投影优化 🔴 **推荐**

**核心**：放弃轴比直接映射，改为 6DOF 位姿空间的非线性最小二乘优化

**初值**: 轴比方法结果  
**目标**: 最小化 100+ 个轮廓点到投影椭圆的距离  
**优化器**: Levenberg-Marquardt 非线性最小二乘

**预期精度**:
- 位置精度：±1-2mm （vs 当前 ±15mm）
- 倾角精度：±0.2° （vs 当前 ±1°）
- 运算时间：15ms （仅优化高质量帧 > 0.6）

**数学原理**:
```
Cost = Σ_i [distance(point_i, project(ellipse(X,Y,Z,θ,φ)))]²

相比轴比方法：
- 轴比：从 2 个参数（a, b）推断 6 个参数（X,Y,Z,θ,φ,ψ）→ 欠定、敏感
- 重投影：用 100+ 个约束拟合 6 个参数 → 超定、稳定

在圆柱上，这相当于"多视角重建"
```

---

### 方案 C: 混合策略（推荐） - Phase A改 + Phase D并行

**短期（1周）**:
